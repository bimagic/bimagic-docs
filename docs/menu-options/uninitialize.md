#  Uninitialize Repo

Safely remove Git version control tracking from the current project directory.

### Features

- **Removes `.git` Directory**: Deletes `.git` folder so the folder becomes a standard directory.
- **Safety Modal**: Requires explicit confirmation (`gum confirm`) before executing.
- **Leaves Files Intact**: Working directory files and source code remain untouched.
