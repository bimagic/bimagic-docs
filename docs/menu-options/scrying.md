# 󰈈 The Scrying Glass (Quick View)

"The Scrying Glass" provides an instant, scrollable preview of any file in your repository—whether tracked by Git or untracked.

### Features

- **Interactive Selection**: Search files quickly using `gum filter`.
- **Side-by-Side Preview**: Uses `fzf` (if installed) for real-time split-screen file previewing while browsing.
- **Scrollable Pager**: Uses `gum pager` for smooth reading of long documents.
- **Magic Highlight**: Uses `bat` (if installed) for automatic syntax highlighting.
