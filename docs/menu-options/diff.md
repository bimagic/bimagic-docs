# 󰈈 Diff & Inspection Wizard

*Available in Bimagic Go Edition*

The **Diff & Inspection Wizard** allows you to inspect changes across your repository interactively (`bimagic --diff`).

### Features

- **Unstaged Diffs**: View working directory diffs (`git diff`).
- **Staged Diffs**: View staged index diffs (`git diff --staged`).
- **Specific File Diffs**: Interactively pick modified files to inspect line-by-line changes.
- **Branch Comparison**: Compare differences between two branches (`git diff branch1..branch2`).
