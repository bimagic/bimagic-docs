#  Push to Remote

Push committed changes from your local branch to the remote repository.

### Features

- **Upstream Auto-Setup**: Automatically configures remote tracking (`git push -u origin <branch>`) if pushing a new branch for the first time.
- **Multi-Remote Support**: Select which remote target to push to.
- **Spinner Feedback**: Displays an interactive progress spinner during network transmission.
