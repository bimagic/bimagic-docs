# Code Blame & Line History

The **Code Blame Inspector** allows developers to view line-by-line commit attribution for any file in the repository.

### Features

- Filter and select any file interactively with fuzzy matching (`fzf`).
- Displays author, commit date, commit hash, and line code side-by-side.
- Integrates with `bat` syntax highlighter when available.

**CLI Keymap**: `wz -B` / `wz --blame`
