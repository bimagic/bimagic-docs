# 󰓹 Tag Operations

*Available in Bimagic Go Edition*

The **Tag Operations** wizard provides full control over Git tags for release management (`bimagic -t`).

### Features

- **Create Tag**: Support for lightweight tags or annotated tags (`git tag -a -m`).
- **List Tags**: View all local tags with subject lines.
- **Push Tags**: Push all tags to remote (`git push origin --tags`).
- **Delete Tag**: Delete local tags (`git tag -d`) or remove remote tags (`git push origin --delete`).
