#  Branch Operations

The **Branch Operations** spell provides complete management over local Git branches.

### Features

- **Switch Branch**: Interactive selector (`gum filter`) with a visual indicator (`➤`) pointing to the active branch.
- **Create Branch**: Prompt for a new branch name and check it out immediately (`git checkout -b <name>`).
- **Rename Branch**: Rename the active branch (`git branch -m <new-name>`).
- **Delete Branch**: Multi-select local branches to delete safely (`git branch -d`) or force delete (`git branch -D`).
