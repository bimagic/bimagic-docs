# Git Submodule Manager

The **Git Submodule Manager** streamlines the management of nested Git repositories and submodules.

### Supported Operations

- **Init & Update Submodules**: Recursively initializes and downloads all nested submodules (`git submodule update --init --recursive`).
- **Sync Submodules**: Syncs remote URL changes across submodules (`git submodule sync --recursive`).
- **Add Submodule**: Interactively add a new submodule repository at a specific path.
- **Submodule Status**: Inspect status of all submodules.

**CLI Keymap**: `wz -M` / `wz --submodule`
