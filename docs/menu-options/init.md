#  Init New Repo

The **Init New Repo** spell initializes a new Git repository in the current working directory or a specified target directory.

### Features

- **Guaranteed `main` Branch**: Automatically creates the repository with the modern `main` default branch (`git init -b main`).
- **Automatic Master-to-Main Renaming**: Ensures seamless compatibility with modern GitHub conventions.
- **Safety Checks**: Prompts for confirmation if a `.git` folder already exists.
