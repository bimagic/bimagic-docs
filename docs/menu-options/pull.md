#  Pull Latest Changes

Fetch updates from remote repositories and merge changes into your local branch (`bimagic -p`).

### Features

- **Fetch All Remotes**: Ensures remote tracking branches are up to date.
- **Conflict Warning**: Notifies you immediately if incoming changes conflict with uncommitted local work.
- **Fast-Forward & Merge**: Smoothly integrates remote updates.
