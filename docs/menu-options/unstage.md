# 󰁯 Unstage Files

*Available in Bimagic Go Edition*

The **Unstage Files** spell allows you to selectively unstage files from your Git index (`git restore --staged`) without losing any of your local working directory edits.

### Features

- **Interactive Multi-Select**: Browse all staged files and select individual entries or bulk `[ALL]`.
- **Safe Operation**: Restores files back to the modified state, keeping your code changes intact.
- **Visual Feedback**: Displays success messages listing all unstaged paths.
