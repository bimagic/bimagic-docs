#  Cherry-Pick Wizard

*Available in Bimagic Go Edition*

The **Cherry-Pick Wizard** lets you search repository commit history with an interactive TUI filter and pluck specific commits to apply onto your current branch (`git cherry-pick <hash>`).

### Features

- **Interactive Search**: Filter history by commit hash or subject line using `gum filter`.
- **Conflict Management**: Automatically detects cherry-pick conflicts and guides resolution.
- **Cross-Branch Application**: Effortlessly port hotfixes or single features across branches.
