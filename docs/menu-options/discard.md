# 󰮘 Discard Local Modifications

*Available in Bimagic Go Edition*

The **Discard Local Modifications** spell lets you interactively select modified files in your working directory and permanently discard uncommitted changes (`git checkout -- <file>`).

### Features

- **Interactive Selection**: Choose specifically which modified files to revert.
- **Safety Confirmation**: Explicit modal confirmation before running destructive checkout operations.
- **Clear Warnings**: Protects against accidental data loss while giving complete control.
